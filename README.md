# Tienda ABAS-TCT

Tienda web estática (GitHub Pages). El catálogo y los precios se leen de la pestaña **Tienda** del Google Sheet "ABAS-TCT Catálogo".

- **Precios y productos:** se editan en el Google Sheet, pestaña Productos. La web se actualiza sola en unos minutos.
- **Fotos:** súbelas a la carpeta `img/` (Add file › Upload files) y escribe el nombre del archivo en la columna Foto del Sheet.
- **WhatsApp, Yape, delivery:** archivo `config.js`.
